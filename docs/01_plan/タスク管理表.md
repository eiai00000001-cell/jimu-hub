# タスク管理表

チケット形式の作業管理表。版数管理の対象外(イテレーションごとに追記する)。

## 凡例

- 種別: フェーズ(案件概要〜総括の11フェーズ)/実装(機能単位の実装タスク)/実装サブタスク(実装タスクの内訳。developerが追加)
- 状態: 未着手/進行中/確認待ち/完了
- 記録: 実装サブタスクはコミットハッシュ、それ以外は成果物パス・版数
- 記入分担: planner=フェーズのタスク・実装タスクの大枠/developer=実装サブタスクの追加・その状態とコミットハッシュ/project-leader=それ以外の状態
