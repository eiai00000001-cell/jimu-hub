# 依頼者確認手順書(イテレーション4)

- 版数: v4.1(2026-10-17)
- 対象: 事務HUB イテレーション4(タスク・期限管理、データベースのバージョン6への移行、バックアップ・復元へのタスクの追加)
- 位置づけ: 依頼者ご本人のMacで実際の操作感をご確認いただくための任意の確認です。**未実施でもテストの完了条件には影響しません**(結果はテスト結果報告書.mdの「要確認事項」に記録します)。
- 対応するテストケース: TC-157(確認1)・TC-158(確認2)・TC-159(確認3)(テストケース.md)

## ご確認にあたっての注意

- **普段お使いのデータには触れないようにしてください。** 確認1は、データのコピーを使います。確認2・確認3は、空のデータ保存先で行います。
- 画面のスクリーンショットをお送りいただく場合は、フォルダ名・ユーザー名・メールアドレスなどが写っていないかご確認ください。
- 確認用の作業フォルダは、確認が終わりましたらお手元のFinderで削除してください(削除はご自身でご判断ください)。

## 準備

1. 最新の`.dmg`(または開発版)から事務HUBを起動できる状態にします。初回の起動許可の手順は操作マニュアルをご覧ください。
2. Finderで、確認用の作業フォルダを作ります(例: デスクトップに「事務HUB確認」フォルダ)。
3. 配布版を、確認用の保存先を指定して起動するには、ターミナルで次のように入力します(`<確認用フォルダ>`は手順2のフォルダの場所)。

```bash
open -n "/Applications/事務HUB.app" --args --user-data-dir="<確認用フォルダ>/データ"
```

## 確認1: 既存データの移行(TC-157)

目的: これまでのデータ(イテレーション3まで)が、新しい版で欠けずに開けることを確認します。

1. Finderで「移動」→「ライブラリを表示」などから、実データのフォルダ`~/Library/Application Support/事務HUB`を、確認用フォルダの中へ**コピー**します(移動ではなくコピーです)。コピー先の名前を「データ」にします。
2. 上の「準備」の3のコマンドで、コピー先の「データ」を指定して起動します。
3. 次を確認します。

| 確認項目 | 期待結果 | 結果(○/×) | メモ |
|---|---|---|---|
| ホームの件数(取引先・見積書・請求書・未収) | 普段の件数と同じ | | |
| 見積書・請求書の詳細(PDF保存済みのもの) | 「改変が疑われます」の警告が出ない | | |
| 入出金・経費の詳細(領収書つきのもの) | 警告が出ない | | |
| 案件管理(ある場合) | 件数・収支が普段と同じ | | |
| 「タスク・期限」を開く | 「該当するタスクはありません」(空の状態) | | |
| 確認用の「データ」フォルダの中の`backups` | `pre-migration_v5_…`という名前のファイルが1つ作られている | | |

4. 確認が終わったら、事務HUBを終了します。

## 確認2: タスク・期限の操作(TC-158)

目的: タスク・期限の画面が、使いやすく動作することを確認します(画面の見た目はモックアップとの違いも含めてご確認ください。★H2)。

1. 「準備」の3のコマンドで、空の保存先(例: 「データ2」)を指定して起動します。
2. 「案件管理」で案件を1件登録します(例: 「ホームページ制作」)。
3. 次の操作を順に行い、確認します。

| 操作 | 期待結果 | 結果(○/×) | メモ |
|---|---|---|---|
| 「タスク・期限」→「+ タスクを登録」。タスク名「資料の送付」、期限日を**昨日の日付**、案件「ホームページ制作」で登録 | タスク詳細に移り、期限日が赤字で「期限超過」と表示される | | |
| 同じ画面で、タスク名を空にして「登録」 | 「タスク名を入力してください」が項目の下に表示される | | |
| もう1件、期限日を**今日の日付**で登録(「打ち合わせ準備」) | 期限超過にならない(今日は期限超過の対象外) | | |
| タスク一覧を開く | 上部の件数が「未完了 2件」「期限超過 1件」で、期限超過が強調される。色だけでなく「期限超過」の文字と「!」が付いている | | |
| 「資料の送付」の「完了にする」 | 確認なしに完了になり、未完了の一覧から消え、期限超過が0件になる | | |
| 状態を「すべて」にして、「未完了に戻す」 | 期限超過に戻る | | |
| 絞り込み(案件・期限「期限超過のみ」・タスク名) | 条件に合うタスクだけが表示される | | |
| 「案件管理」→「ホームページ制作」の詳細 | 「紐づくタスク」にタスクが表示され、収支には影響しない | | |
| タスクの「削除」 | 確認が出て、「はい」で削除される | | |
| 案件「ホームページ制作」を削除(紐づくタスクがある状態) | 確認に「紐づくタスク○件は削除されず、「案件なし」に戻ります」と出る。削除後、タスクは残り案件が「案件なし」になる | | |
| 登録画面で、入力途中にサイドバーのメニューを押す | 「入力中の内容は保存されません。この画面を離れてよろしいですか」が出る | | |

4. 画面全体の見やすさ・配色・文字の大きさ・操作のしやすさについて、お気づきの点があればメモ欄にご記入ください。

## 確認3: タスクを含むバックアップ・復元(TC-159)

目的: タスクがバックアップに含まれ、復元で元に戻ることと、OS標準のダイアログの見た目を確認します。

1. 確認2で使った保存先で、タスクを2〜3件用意します(未完了・完了を混ぜてください)。
2. ホームの「データをエクスポート」→「エクスポート実行」を押します。
   - 保存ダイアログの初期の保存先(「書類」)・ファイル名(`事務HUB_backup_日付_時刻.zip`)が表示されることを確認し、確認用フォルダに保存します。
3. 事務HUBを終了し、別の空の保存先(例: 「データ3」)を指定して起動します。
4. 「データを復元」→「ファイルを選択して復元」で、手順2のファイルを選びます(選択ダイアログに`.zip`のファイルが選べることを確認)。
5. 次を確認します。

| 確認項目 | 期待結果 | 結果(○/×) | メモ |
|---|---|---|---|
| 復元前の確認画面 | 出ない(タスクを含むバックアップのため) | | |
| 「タスク・期限」(状態「すべて」) | 手順1のタスクが、状態・期限日・案件・メモとも同じ内容で戻っている | | |
| 完了のタスクの詳細 | 完了日時が表示される | | |

6. (任意)タスクを含まない古いバックアップ(イテレーション3以前に作ったZIP)がある場合は、タスクがある状態で復元しようとすると、「このバックアップにはタスクのデータが含まれていないため、復元すると現在のタスク(○件)はすべて消えます。」と表示され、「キャンセル」が選ばれた状態になっていることを確認してください。「キャンセル」を押して中止します。
