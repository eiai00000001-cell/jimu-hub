### 2.1 今回のイテレーションで追加・変更した主な内容

- 入金・経費の記録(登録・編集・削除)、日付・金額・取引先・勘定科目・種別による検索、変更履歴の記録と確認
- 勘定科目の管理(初期科目のほか、追加・名称変更・利用停止)
- 請求書を「入金済み」にすると、入金の記録が自動で作られる機能(「未収に戻す」と、その記録は「取消済」として残ります)
- 領収書(PDF・JPEG・PNG)の添付と、保存後に書き換えられていないかを確認する仕組み(SHA-256)
- 月別・年別の集計と、勘定科目別の経費合計
- 期間を指定したCSV出力(Excel等で開けます)
- 利用停止にした取引先を「利用中」へ戻す操作(★N1の解消)、下書きの見積書・請求書の削除(★N2の解消)
- エクスポート・復元を、入出金・経費・領収書にも対応(データベースの版 3 → 4。起動時に自動で移行されます)
- 大きなデータの書き出し・復元時の案内の改善(1GiBを超える場合は書き出しを中止して案内します)

## 5. セットアップ手順

このアプリは、依頼者ご本人のMacに直接インストールしてお使いいただくローカル完結型のデスクトップアプリです。インターネット環境は不要です。

- インストール・既存の0.2.0からの更新手順は、操作マニュアル.md 2章に記載しています。**更新の前に、現在の事務HUB(0.2.0)でデータのエクスポートを行ってください。**
- 起動時に、データの形式が自動的に新しい版へ移行されます(データベースの版 3 → 4)。この移行は自動テストで確認済みです。依頼者ご本人のMacでの実機確認は7章をご覧ください。
- 開発作業を引き継ぐ場合の手順(`npm install`、`npm run dev`、`npm run dist:mac`等)は、README.md 3章に記載しています。このうち`npm run dist:mac`(配布用`.dmg`の作成)は、本納品フェーズでも実際に実行し、成功を確認しました(6章参照)。その他の開発用コマンドは前フェーズで実行・確認済みのもので、本フェーズでは再実行していません。
