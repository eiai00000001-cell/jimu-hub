### 2.1 今回のイテレーションで追加・変更した主な内容

- 見積書・請求書の作成、PDF保存、見積書から請求書への変換、入金状況の管理、源泉徴収税額の自動計算
- 自社情報・振込先の設定、取引先のフリガナ(五十音順の並べ替えに対応)
- エクスポート・復元を、PDFも含めたZIPファイル形式へ変更(従来のJSONファイルも復元できます)
- アプリが起動できないとき(データの破損時)に、起動エラー画面からそのまま復元できる機能
- アプリアイコンの設定、配布物から不要な同梱物を除外(SEC-07対応)
- 電子帳簿保存法への対応として、PDF保存時の改変検知用の記録(SHA-256)と、日付・金額・取引先による検索

## 5. セットアップ手順

このアプリは、依頼者ご本人のMacに直接インストールしてお使いいただくローカル完結型のデスクトップアプリです。インターネット環境は不要です。

- インストール・既存の0.1.0からの更新手順は、操作マニュアル.md 2章に記載しています。**更新の前に、現在の事務HUB(0.1.0)でデータのエクスポートを行ってください**(0.1.0のデータは動作確認用とお伺いしていますが、念のためです)。
- 起動時に、データの形式が自動的に新しい版へ移行されます(データベースの版 1 → 3)。この移行は自動テストで確認済みですが、依頼者ご本人のMacでの実機確認は7章のとおりです。
- 開発作業を引き継ぐ場合の手順(`npm install`、`npm run dev`、`npm run dist:mac`等)は、README.md 3章に記載しています。このうち`npm run dist:mac`(配布用`.dmg`の作成)は、本納品フェーズでも実際に実行し、成功を確認しました(6章参照)。その他の開発用コマンドは前フェーズで実行・確認済みのもので、本フェーズでは再実行していません。
