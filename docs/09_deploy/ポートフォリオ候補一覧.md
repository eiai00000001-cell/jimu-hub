## 4. 今後の検討事項

- 今回のイテレーションでは、実機(配布版`.app`)を操作した際のスクリーンショットは撮影していません。デザインフェーズのモックアップ(上記一覧)のみが候補です。実際に動作するアプリの画面キャプチャがあると、ポートフォリオとしての説得力がより高まりますので、次回イテレーション以降で撮影を検討されることをおすすめします。
- 配布用`.dmg`のファイルサイズ・SHA-256・未署名配布への対応など、セキュリティ面の取り組み(セキュリティチェック結果報告書.md参照)は画像では伝わらない要素です。文章での実績紹介と組み合わせることをおすすめします。
