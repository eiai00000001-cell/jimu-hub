既定: {} → 同じ期限の先 / 同じ期限の後 / 過去の期限 / 今日が期限 / 100%達成 / 遠い期限 / 期限なし1 / 期限なし2 / a_b確認 / aXb確認
状態=完了: {"status":"done"} → 完了済みの過去
状態=すべて: {"status":"all"} → 完了済みの過去 / 同じ期限の先 / 同じ期限の後 / 過去の期限 / 今日が期限 / 100%達成 / 遠い期限 / 期限なし1 / 期限なし2 / a_b確認 / aXb確認
案件なし: {"status":"all","projectId":null} → 同じ期限の先 / 100%達成 / 期限なし1 / a_b確認 / aXb確認
案件=A: {"projectId":1} → 今日が期限 / 遠い期限
案件=B(完了の案件でも絞れる): {"projectId":2} → 同じ期限の後 / 過去の期限 / 期限なし2
期限なしのみ: {"dueMode":"none"} → 期限なし1 / 期限なし2 / a_b確認 / aXb確認
期限超過のみ: {"dueMode":"overdue"} → 同じ期限の先 / 同じ期限の後 / 過去の期限
期間指定(今日〜明日): {"dueMode":"range","dueFrom":"2026-10-17","dueTo":"2026-10-18"} → 今日が期限 / 100%達成
期間指定(開始のみ=今日): {"dueMode":"range","dueFrom":"2026-10-17"} → 今日が期限 / 100%達成 / 遠い期限
期間指定(終了のみ=昨日): {"dueMode":"range","dueTo":"2026-10-16"} → 同じ期限の先 / 同じ期限の後 / 過去の期限
期間指定(両方空=すべて): {"dueMode":"range"} → 同じ期限の先 / 同じ期限の後 / 過去の期限 / 今日が期限 / 100%達成 / 遠い期限 / 期限なし1 / 期限なし2 / a_b確認 / aXb確認
キーワード「%」: {"keyword":"%"} → 100%達成
キーワード「_」: {"keyword":"_"} → a_b確認
キーワード「a_b」: {"keyword":"a_b"} → a_b確認
キーワード「期限」(部分一致): {"keyword":"期限"} → 同じ期限の先 / 同じ期限の後 / 過去の期限 / 今日が期限 / 遠い期限 / 期限なし1 / 期限なし2
AND条件(案件A×期限超過): {"projectId":1,"dueMode":"overdue"} → (0件)
AND条件(案件B×期限超過×キーワード): {"projectId":2,"dueMode":"overdue","keyword":"過去"} → 過去の期限
期間の逆転: 拒否「期限の終了日は、開始日以降の日付を入力してください」
不正な日付・状態: 拒否(日付は「YYYY-MM-DD」形式の正しい日付で入力してくだ / 拒否)
